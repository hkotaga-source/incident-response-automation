# Post-Incident Checklist

- [ ] Incident resolved and all alerts cleared
- [ ] Status page updated to green
- [ ] Customer communication sent (if needed)
- [ ] Timeline captured
- [ ] Root cause identified (or investigation ticket created)
- [ ] Action items assigned with owners and due dates
- [ ] Postmortem document started
- [ ] Runbooks updated if gaps found
- [ ] Monitoring / alerting improved
- [ ] Blameless culture maintained
